# Oppervlakte & Inhoud

Leerplatform voor Groep 7 - Leer hoe je de oppervlakte en inhoud van verschillende vormen berekent.

## Online gebruiken

Je kunt deze app direct online gebruiken via:

https://spoorcc.github.io/oppervlakte-inhoud/

## Lokaal gebruiken

1. Download de `index.html` bestand
2. Open het bestand in je browser

Of gebruik een lokale server:

```bash
# Met Python
python -m http.server 8000

# Met Node.js
npx serve .
```

## Kenmerken

- 📐 Leer oppervlakte berekenen: Vierkant, Rechthoek, Driehoek, Cirkel
- 📦 Leer inhoud berekenen: Kubus, Blok, Cilinder, Piramide, Bol
- ⭐ Verdien stappen door vragen correct te beantwoorden
- 🐦 Bonus: Flappy Vorm spel na 5 correcte antwoorden
- 💾 Je voortgang wordt automatisch opgeslagen
